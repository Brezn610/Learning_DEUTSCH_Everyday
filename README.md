# Learning Deutsch Everyday 🇩🇪

> Daily Spoken German — Jeden Tag Deutsch  
> 每天 10–15 分钟练口语，外加 A1–B2 词汇与语法扩展训练。重点是德国真实生活中的自然交流。

## 学习方法

每期课程采用 **Topic A → Topic B**：从一个主话题出发，经由自然的回答、追问或生活线索过渡到另一个相关话题。目标不只是会回答，还要能接话、反问、延续对话。

- **语言**：中文讲解 + 自然的标准德语口语；主对话 A2–B1，词汇与语法广度覆盖 A1–B2。
- **场景**：德国生活、住房、交通、大学、餐饮、医疗、行政事务、求职、同事闲聊、科技/AI、旅行与文化。
- **参考**：[ZDF logo!](https://www.zdf.de/kinder/logo)、[DAAD](https://www.daad.de/)、[DW Deutsch lernen](https://learngerman.dw.com/)、[Goethe-Institut](https://www.goethe.de/)。仅在核实具体节目或材料后才引用原始链接；对话内容保持原创。
- **学习节奏**：德国时间（Europe/Berlin）每天早上 08:00 接收 ChatGPT 学习课程，并尝试同步保存至本仓库。核心口语约 10–15 分钟，完整 50 项词汇扩展通常还需约 20–30 分钟。GitHub 归档成功与否以实际提交为准。

## 课程目录

每日课程保存为：

```text
lessons/YYYY/MM/YYYY-MM-DD.md
```

例如：[2026-10-13 第 01 期：购物→生活成本](lessons/2026/10/2026-10-13.md)。

这样按年、月归档，便于 Git 历史追踪、检索与后续扩展。

## 每日课程结构

1. **今日双话题**：Topic A → Topic B，以及顺畅转题的原因。
2. **原创情景对话**：约 10–14 个双人短回合，关键表达配中文解释。
3. **每日 50 项高频词汇和固定搭配**：覆盖 A1 / A2 / B1 / B2（参考配比 12 / 14 / 14 / 10）；每项有标准德语 IPA、中文、简单例句。名词标冠词与复数；动词标 ich / du / er-sie-es 现在时，补充 Präteritum 和 Perfekt；介词固定搭配标 Akk. / Dat.，跨日常、大学、工作多个场景。约 12–15 项主动掌握，其余扩展识别并定期复现。
4. **日常高频句型**：2–3 个，特别关注追问、接话和自然过渡。
5. **发音训练**：1–2 个词重音、发音难点或自然语流要点。
6. **微型语法与词形**：一个直接服务于当天口语的知识点，辅以重要动词变位、时态对比以及常见复数规律。
7. **互动练习**：2–3 个连贯问题或角色扮演，鼓励主动用德语回答。

## 归档原则

- 同一天只创建一份课程，避免重复推送造成重复文件。
- 不覆盖旧课程；如果需要修正，保留 Git 提交历史。
- 不伪造官方节目、音频、视频或参考来源。
- 保持 Markdown 简洁易读，使人和 AI 都能方便地检索、整理、拓展。
- 每天的对话主题尽量与近期课程不同，同时定期复现已学表达。

---

**目标：** 从日常简短问答，逐步提高到能够主动接话、讲述经历、讨论观点，最终完成 10–30 分钟的自然德语交流。
