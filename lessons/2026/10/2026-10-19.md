# 🇩🇪 Daily Spoken German — Day 07
**2026-10-19｜A1–B2｜Paket abholen → Rücksendung und Kundenservice**

核心口语 10–15 分钟，50 项词汇与语法拓展 20–30 分钟。⭐ 为今日 15 项主动词汇；其余 35 项先识别。等级为教学参考。

## 1. 原创对话（14 回合）

**Mila:** Hast du nach der Vorlesung kurz Zeit? Ich muss noch ein Paket abholen.  
下课后有空吗？我得去取包裹。

**Noah:** Klar. Wo liegt es denn?  
当然。包裹在哪儿？

**Mila:** In einer Filiale. Der Zusteller hat gestern niemanden angetroffen.  
在网点。快递员昨天没找到收件人。

**Noah:** Hast du eine Benachrichtigung bekommen?  
你收到通知了吗？

**Mila:** Ja, per E-Mail. Ich soll meinen Ausweis mitbringen.  
收到了，邮件通知的。要带身份证件。

**Noah:** Dann gehen wir zusammen hin. Was hast du bestellt?  
一起过去吧。你买了什么？

**Mila:** Eine Tastatur für mein Projekt. Aber ich glaube, ich habe das falsche Modell ausgewählt.  
项目用的键盘，但我好像选错型号了。

**Noah:** Ach so. Kannst du sie zurückgeben?  
原来如此。能退吗？

**Mila:** Wahrscheinlich. Ich muss nur den Kaufbeleg finden.  
应该能。我得先找到购买凭证。

**Noah:** Schau mal in dein Kundenkonto. Dort kannst du oft die Rücksendung anmelden.  
看看客户账户，通常能在那儿申请退货。

**Mila:** Guter Tipp. Wenn die Tastatur beschädigt ist, sollte ich mich direkt an den Kundendienst wenden, oder?  
好建议。如果键盘损坏，我该直接联系客服，对吧？

**Noah:** Genau. Beschreib den Fehler möglichst genau und häng ein Foto an.  
对，尽量准确描述问题，附上照片。

**Mila:** Wie bei unserer Uni-Abgabe: Man muss alles gut dokumentieren.  
就像大学交作业：什么都要记录清楚。

**Noah:** Stimmt. Bevor du die Datei hochlädst, überprüf lieber noch mal den Anhang.  
没错。上传文件前，最好再检查一遍附件。

**自然转题：** 取件 → 型号错误 → 退货 → 客服沟通 → 大学/工作中的文档。*Ach so.*（原来如此）、*Guter Tipp.*（好建议）、*Schau mal ...*（你看看……）。

## 3. 主动追问与接话

**Wo kann ich ... abholen?** — 在哪里领取？*Wo kann ich mein Paket abholen?* 追问：*Brauche ich meinen Ausweis?*

**Könnten Sie mir bitte ...?** — 您能否……？*Könnten Sie mir bitte sagen, wie die Rücksendung funktioniert?*

**Meine Frage bezieht sich auf ...** — 我的问题关于……。*Meine Frage bezieht sich auf die Abgabe nächste Woche.* 适用于教授、客服与工作邮件。

## 4. 发音与语流

**重音：** *Paket* /paˈkeːt/、*Karton* /kaʁˈtɔŋ/ 重音在后一个音节；*Ausweis* /ˈaʊ̯svaɪ̯s/ 重音在前。

**可分动词：** *Ich hole das Paket **ab**.*；*Ich fülle das Formular **aus**.* 前缀在句末读清楚；从句不拆：*..., weil ich das Paket morgen **abhole**.*

## 5. 微型语法：可分动词与时态

**主句：** *Ich hole das Paket morgen ab.*（明天取件。）  
**weil 从句：** *Ich gehe zur Filiale, weil ich das Paket abhole.*（因为要取件所以去网点。）  
**Perfekt：** *Ich habe das Paket gestern abgeholt.*（昨天取了。）

| 人称 | abholen | sich wenden an + Akk. |
|---|---|---|
| ich | hole ... ab | wende mich an ... |
| du | holst ... ab | wendest dich an ... |
| er/sie/es | holt ... ab | wendet sich an ... |
| wir | holen ... ab | wenden uns an ... |
| ihr | holt ... ab | wendet euch an ... |
| sie/Sie | holen ... ab | wenden sich an ... |

**时态对照 1：** Präsens *Ich hole das Paket ab.* → Perfekt *Ich habe das Paket abgeholt.* → Präteritum *Ich holte das Paket ab.*

**时态对照 2：** Präsens *Ich wende mich an den Kundendienst.* → Perfekt *Ich habe mich an den Kundendienst gewandt.* → Präteritum *Ich wandte mich an den Kundendienst.*

口语叙述具体过去动作多用 **Perfekt**，书面叙述多用 **Präteritum**；但 *war、hatte、konnte、musste* 在口语也常用。

**复数举例：** *Paket → Pakete*（-e）；*Adresse → Adressen*（-n）；*Laden → Läden*（变音）；*Formular → Formulare*（-e）；*Anhang → Anhänge*（变音+-e）。

## 6. 三轮口语实战

**① 柜台取件：** 用德语说“我想取包裹；这是我的证件；需要签字吗？”至少 3 句，使用 *Könnten Sie ...?*。

**② 联系客服：** *Du hast die falsche Tastatur bekommen. Wie erklärst du das Problem und worum bittest du?* 用 *Meine Frage bezieht sich auf ...* 和 *Ich bitte um ...*。

**③ 大学项目：** *Du musst eine Datei hochladen, aber der Anhang fehlt. Was machst du?* 用 3–4 句说明补救措施。

**旧词复现（不计入 50 项）：** Day 03 *etwas klären*、Day 04 *sich konzentrieren auf + Akk.*、Day 06 *etwas einhalten*。例：*Ich muss das Problem klären und mich auf die Abgabe konzentrieren, damit wir die Frist einhalten.*
